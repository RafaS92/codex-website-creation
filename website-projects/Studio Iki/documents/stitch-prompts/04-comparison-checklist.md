# Studio IKI — Stitch Direction Comparison Checklist

## Review Setup

Compare Directions A, B, and C only after each has generated the complete canonical website in its own Stitch agent thread or branch.

For a fair review:

- Display the directions side by side in the same order: A, B, C.
- Use the same page order in every review: Home → Jikiden Reiki Seminar → Therapies → About & Philosophy → Events → FAQ → Contact / Inquiry → Privacy Policy → Terms / Booking Policy.
- Compare matching screens at the same viewport width and approximate scroll position.
- Review desktop first, then mobile, then component and interaction states.
- Do not reward a direction for adding content, pages, features, claims, or assets that the others do not have. Record these as parity failures.
- Do not select a direction until content parity has been checked.

## Direction Review Scorecard

Score each category from 1 to 5:

- **1 — Poor:** conflicts with the approved strategy or creates major usability concerns.
- **2 — Weak:** partially fits, with substantial correction required.
- **3 — Sound:** meets the requirement but has notable opportunities to improve.
- **4 — Strong:** fits very well with only modest refinement required.
- **5 — Excellent:** expresses the requirement clearly, distinctively, and credibly.
